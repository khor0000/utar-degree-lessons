Reading a permission string

The ten characters at the start of an ls -l line say what the item is and who may do what with it.

Lesson 3 made files and folders. Now run ls -l on them and read who may touch each one.

Looks like the terms authentication and authorization from Topic 1: this string is authorization, deciding what an already logged-in user may do.

A worked line

-rw-r--r-- 1 tanah students 35635 2011-06-08 02:41 myfile.txt

Reading left to right: permissions, link count, owner (tanah), group (students), size in bytes, date and time, name. Only the first four matter for this lab.

Split it into 1 + 3 + 3 + 3

The first character is the type: d for a directory, - for a file. Then come three sets, always in the order owner, group, others (everyone else). Each set is always in the order r read, w write, x execute. A - inside a set means that right is off. A permission is one of these on/off rights.

You might reasonably wonder: how do you execute a photo? You do not. x only allows a file to be run, and a photo holds image data, not instructions, so it normally has no x. A viewer program opens it, which needs only r.

Files and directories are the two types you use in Lab 1, but not the only ones: l in the first slot marks a symbolic link, for example.

Which set applies to you?

The system uses only one set. If you are the owner, it uses the owner set. Otherwise, if you belong to the group, it uses the group set. Otherwise it uses others. A group is a named list of users, so several people can share access without opening it to everyone. For -rw-r----- ali students report.txt, ali reads and writes, anyone in students only reads, and everyone else gets nothing.

Looks like private user folders on Windows. Neither system gives each user a separate file system: both share one, and permissions create the separation. Administrators on Windows and root on Linux can get past it.
Critical Exam Trap • Read the Sets in Order

Never read the string as one run. Split after the first character, then every three.

Correct (earns marks)Incorrect (loses marks)
- rw- r-- r---rw -r- -r--

For -rw-r-----, what can someone in the group do?

Yes. The group set is r--.
Split it: -, rw-, r--, ---. The middle set is the group.
Procedure drill (fresh input)

Decode drwx--x--- and -r-xr-xr-x into type, owner, group and others.

Reveal the answer

drwx--x---: directory; owner rwx; group x only; others nothing.

-r-xr-xr-x: file; owner, group and others each have read and execute, and nobody has write.
