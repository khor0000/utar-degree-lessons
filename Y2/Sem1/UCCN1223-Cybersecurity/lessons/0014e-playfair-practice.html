Playfair part 5: practice

Practice means encrypting each pair from the grid, not from the worked runs, and then running a longer message with its own keyword grid.

Bridge: lesson 14d ran two full messages with the MONARCHY grid. This lesson gives you blank pairs and a longer message to run yourself.

1. Slide 43: six blank pairs

Slide 43 leaves six pairs blank: in, ru, sz, AT, TA, CK, all with MONARCHY. The runs in lesson 14d already give their answers, so work from the grid and not the table when you answer.

Encrypt the pair in with MONARCHY.

Yes. I and N are a rectangle: GA.
I and N share no row or column. I takes its own row at N's column, so the output starts with G.

Encrypt the pair ru with MONARCHY.

Yes. R takes column 1 of its row (M), and U takes column 5 of its row (Z).
R and U form a rectangle. R stays in row 1 and takes column 1: M. Work out U the same way.

Encrypt the pair sz with MONARCHY.

Yes. S takes T, and Z takes X.
S is in row 4 and Z in row 5, so they form a rectangle. S takes column 5 of row 4: T.

Encrypt the pair AT with MONARCHY.

Yes. A takes R, T takes S.
A and T form a rectangle. A is in row 1, so it takes the letter in row 1 at T's column: R.

Encrypt the pair TA with MONARCHY.

Yes. T takes S, then A takes R. The order of the pair decides the order of the output.
Same corners as AT, but in the other order. T is in row 4, so it takes the letter in row 4 at A's column: S.

Encrypt the pair CK with MONARCHY.

Yes. C takes D, K takes E.
C is in row 2 and K in row 3, so they form a rectangle. C takes the letter in row 2 at K's column: D.
Show the steps for in, ru, sz
  1. in: I is at row 3, column 4. N is at row 1, column 3. Rectangle. I takes row 3, column 3: G. N takes row 1, column 4: A. Answer GA.
  2. ru: R is at row 1, column 5. U is at row 5, column 1. Rectangle. R takes row 1, column 1: M. U takes row 5, column 5: Z. Answer MZ.
  3. sz: S is at row 4, column 4. Z is at row 5, column 5. Rectangle. S takes row 4, column 5: T. Z takes row 5, column 4: X. Answer TX.
Show the steps for AT, TA, CK
  1. AT: A is at row 1, column 4. T is at row 4, column 5. Rectangle. A takes row 1, column 5: R. T takes row 4, column 4: S. Answer RS.
  2. TA: the same corners in the other order. T takes row 4, column 4: S. A takes row 1, column 5: R. Answer SR.
  3. CK: C is at row 2, column 1. K is at row 3, column 5. Rectangle. C takes row 2, column 5: D. K takes row 3, column 1: E. Answer DE.

2. Pick the pair's output order

For the rectangle pair TA, which row decides the first output letter?

Yes. Each letter's output comes from its own row, and the first output letter comes from the first letter's row. T is in row 4, so TA starts with S.
The first output letter comes from the first letter's row, which is T's row. T is in row 4, so the output starts with S, not R. Row 1 belongs to A, which comes second.

3. Slide 46: TREE IS GREEN

Slide 46 runs a longer message with a different keyword, ENVIRONMENT.

Encrypt TREE IS GREEN with the keyword ENVIRONMENT. Use the filler X. Type the ciphertext.

Yes. The pairs are TR EX EI SG RE EN.
First cut the message into pairs with the filler X: TR EX EI SG RE EN. Then apply a rule to each pair, using the grid.
Show the steps
ENVI/JR

KLPQS
UWXYZ
  1. TR: rectangle. T is at row 2, column 3. R is at row 1, column 5. T takes row 2, column 5: B. R takes row 1, column 3: V. Output BV.
  2. EX: rectangle. E is at row 1, column 1. X is at row 5, column 3. E takes row 1, column 3: V. X takes row 5, column 1: U. Output VU.
  3. EI: same row 1. E takes N. I (column 4) takes R (column 5). Output NR.
  4. SG: rectangle. S is at row 4, column 5. G is at row 3, column 4. S takes row 4, column 4: Q. G takes row 3, column 5: H. Output QH.
  5. RE: same row 1. R is in the last column, so it wraps to column 1: E. E takes the letter to its right: N. Output EN.
  6. EN: same row 1. E takes N. N takes V. Output NV.

Ciphertext: BV VU NR QH EN NV.
