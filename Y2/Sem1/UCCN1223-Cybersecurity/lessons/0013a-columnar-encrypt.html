Columnar transposition: write in rows, read in columns

Columnar transposition writes the message in rows under a keyword, then reads the columns in the alphabetical order of the keyword's letters. The letters never change. Only their positions do.

Why this matters: lesson 9 showed HELLO becoming HLOEL, a rearrangement with no key. This is the version with a keyword that you can do by hand. Focus on: the grid, the column order, and reading columns in number order. Skip for now: the theory of why rearranging helps (slide 15). How you'll be tested: by hand, no calculator. Looks like the keyword ciphers (lessons 12a to 12d), but... they also start from a keyword, so the key looks the same. They substitute: each letter is swapped for another letter, and the letters change. Columnar transposition swaps no letters. The name "keyword transposed" on slide 33 is misleading: its letters change too.
Looks like the two-row strip (lesson 11), but... the strip swaps letters; columnar moves them, and the letters stay the same.

1. The keyword sets the column order

A keyword is a word both sides agree on in advance. Its letters decide the order in which the columns are read. Take GERMAN. Number its letters in alphabetical order: A is 1, E is 2, G is 3, M is 4, N is 5, R is 6. Those numbers, not the letters, tell you what to read first.

Repeated letters in a keyword are not on the slides, so this lesson uses only keywords with no repeats.

2. The rule, and where the padding goes

General rule (encrypt): (1) number the keyword's letters alphabetically; (2) write the message in rows, as many letters per row as the keyword has letters; (3) fill the empty cells of the last row with the padding letter; (4) read the columns in number order, top to bottom.

A padding letter is a filler, here X.

Slide 14 says the message has 16 letters. Count it: DEFENDTHEEASTWALL has 17. So there is one padding letter, not two. The grid on the slide is correct; only its count is wrong.

Critical Exam Trap • Start with the Numbered Column

Columns are read in number order, not left to right. The first column read is the one under number 1.

Check yourself

Do this on a blank page first. The keyword is CHAIR and the message is MEET ME AT NOON. Encrypt it, then reveal each step.

Reveal the answer, step by step
  1. Number the keyword: C is 2, H is 3, A is 1, I is 4, R is 5.
  2. Remove the spaces: MEETMEATNOON has 12 letters. Five per row gives 3 rows, 15 cells, so 3 padding letters.
  3. Rows: MEETM / EATNO / ONXXX.
  4. Read in number order. Number 1 is the A column (column 3): E T X. Number 2 is the C column (column 1): M E O.
  5. Number 3 is the H column (column 2): E A N. Number 4 is the I column (column 4): T N X. Number 5 is the R column (column 5): M O X.
  6. Join the pieces: ETXMEOEANTNXMOX.

In columnar transposition with keyword GERMAN, what happens to the first D of DEFEND?

Yes. The letters never change. This D is in the G column, which is read third, so it becomes the seventh letter of the ciphertext.
No letter is swapped or shifted in columnar transposition. Only X is ever added, as padding, at the end of the last row. The D keeps its identity and changes position.
