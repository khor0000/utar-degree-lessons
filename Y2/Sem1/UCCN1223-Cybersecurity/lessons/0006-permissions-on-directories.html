rwx means something else on a directory

On a directory, r lists the names, w changes what is inside, and x lets you enter.

Looks like lesson 4’s file rights. The letters and digits are identical. Only the meaning changes, and the reason is that a directory holds a list of names, so "run it" makes no sense and x gets a new job.

Same letters, new jobs

BitOn a fileOn a directory
rRead the contentsList the names inside
wChange the contentsCreate and delete items inside
xRun it as a programEnter it with cd and reach items inside

This comes from Topic 2 slide 28.

The catch in Lab 1 Question 4

Q4 says to make a folder "only readable and writable by you". Reading that literally gives 600, but with x off you cannot enter your own folder. Run it as an ordinary user and watch:

$ mkdir ChooAhChooOnly
$ chmod 600 ChooAhChooOnly
$ ls -ld ChooAhChooOnly
drw------- 2 ...
$ cd ChooAhChooOnly
bash: cd: ChooAhChooOnly: Permission denied
$ chmod 700 ChooAhChooOnly
$ cd ChooAhChooOnly
$ pwd
/home/student/ChooAhChooOnly

The -d in ls -ld shows the folder’s own line, not its contents. In the lab you may be root from sudo su, and root skips this check, so cd would succeed and hide the problem. Test as a normal user. If the marker wants the literal wording, 600 is what the sheet says; 700 is what works. Tell the instructor why you chose it.

Critical Exam Trap • Folders Need x

A private folder you can actually use needs the owner’s x.

Correct (earns marks)Incorrect (loses marks)
chmod 700 mydirchmod 600 mydir

A folder is drwxr-xr-x. Who can create a file inside it?

Yes. Only the owner set has w.
On a directory, creating an item needs w. Look at which sets have it.
Procedure drill (fresh input)

Write the chmod for a folder shared where the owner has full access, the group can enter and list, and others have nothing.

Reveal the answer

chmod 750 shared. Group needs r to list and x to enter, so 4 + 1 = 5.
