The Hill cipher, mod 26

A Hill block is encrypted by multiplying its column of letter-numbers by a 2×2 key matrix, then taking each result mod 26.

Why this matters: Hill mixes letters with arithmetic on their numbers, not with a table lookup. Each output letter depends on both letters of its block, which is why it is stronger than swapping one letter for one letter. The wrap is the mod 26 from lesson 15a, and the size rule for the multiply is in lesson 16. Focus on: one encryption with every multiply and every mod 26 written down. Skip for now: keys bigger than 2×2, and the general method for them. How you'll be tested: by hand, every step shown (old-format paper Oct 25 Q1, Hill encrypt, 4 marks; the format changed from June 2026). The Casio fx-570EX matrix mode can do the multiply, but no source here gives its key presses, so they are not confirmed.

Bridge: Caesar in lesson 11 wrapped one letter past Z. Hill wraps a whole block the same way, at once. The size rule that lets the key multiply a block is in lesson 16.

1. Padding and the letter numbers

Letters become numbers with A = 0, B = 1, up to Z = 25. HELLO gives H = 7, E = 4, L = 11, L = 11, O = 14. A block (lesson 16) needs two letters, and HELLO has five. So the message gets a padding letter, a filler, and it is split into blocks: HE, LL, OX.

Looks like Playfair (lesson 14b), which pads an odd length with Z, and columnar (lesson 13a), which fills empty cells with X. Why it differs: Hill only needs a complete block. The slide's own example uses X, written “e.g., X”, so the letter is a choice here, not a fixed rule.

The Hill rule: C=KP mod 26. P is the block as a column (lesson 16), K is the key. Multiply each row of K by the block, add the two products, then take each sum mod 26 and read the letter.
Keep the numbers small: reducing early gives the same answer: 16 + 17 = 33, which is 7 mod 26.

4. The key must be invertible mod 26

A key is invertible mod 26 when it has an undo mod 26. Test it with the determinant, one number from the key, ad − bc.

For any 2×2 key, name the four entries a, b, c and d, with a and b in the top row:

A=[abcd]
Determinant. What it is: one number worked out from the four entries of a 2×2 key. What it holds: ad − bc. For K, a = 3, b = 3, c = 2, d = 5, so 3 × 5 − 3 × 2 = 9. Why needed: it tells you whether the key can be undone mod 26.

The key is valid when gcd(9, 26) = 1. The gcd is the greatest common divisor, the largest number that divides both. Here it is 1, so 9 and 26 are coprime: they share no factor except 1.

Why: if the determinant shares a factor with 26, two different blocks can encrypt to the same pair, so the message cannot be read back.

Fresh check: block SY (not shown above)

Encrypt SY with the same key K=[3325]. S = 18 and Y = 24. Work it on paper before you open the reveal.

Reveal, step by step
  1. Top entry: 3 × 18 + 3 × 24 = 54 + 72 = 126.
  2. Bottom entry: 2 × 18 + 5 × 24 = 36 + 120 = 156.
  3. Mod 26: 126 − 104 = 22, since 26 × 4 = 104. And 156 − 156 = 0, since 26 × 6 = 156.
  4. 22 is W, and 0 is A. So SY → WA.
