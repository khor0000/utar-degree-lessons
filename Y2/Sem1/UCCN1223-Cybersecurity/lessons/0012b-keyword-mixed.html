The keyword mixed cipher: the same keyword, read down a grid

A keyword mixed cipher starts from the same keyword as lesson 12a, but it puts the unused letters into a grid, and the cipher row is read down the columns of that grid.

Bridge: this lesson uses the same keyword, but the unused letters are not read in one line. They go into a grid first.

Anatomy of a keyword mixed cipher. (1) What it is: a substitution cipher whose cipher row is read from a grid built from a keyword. (2) What value it holds: one 26-letter cipher row, fixed for the whole message. (3) Why it is needed: the grid, not the keyword alone, decides which letter each plain letter becomes.
Looks like 12a, but… both start from a keyword and both are monoalphabetic (lesson 12a): one fixed cipher row for each message. The difference is how that row is made. The table shows the difference.

You might reasonably wonder: why not read the grid across? Reading across gives A B C D F G, which is not a cipher row.
Critical Exam Trap • Grid Width Is the Unique Letters

The grid is as wide as the keyword's unique letters, not its length. Keyword ASSESS has three unique letters, so the grid is three wide.

Yes. Each plain letter is replaced by the cipher-row letter, and that row is read down the columns of the grid.
Mixed is still substitution: letters are replaced, not moved. The grid is read down its columns, and a fixed shift is the Caesar idea.
