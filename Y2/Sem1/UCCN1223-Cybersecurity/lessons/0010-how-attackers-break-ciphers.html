How attackers break ciphers

An attacker breaks a cipher either by trying every key until a result reads as a real message, or by reading patterns in the ciphertext.

Lesson 9 turned HELLO into KHOOR by replacing each letter, and into HLOEL by shuffling them. This lesson asks how an attacker gets the message back without the key.

1. How an attacker breaks a cipher

Looks like the same job, both get the message back without the key, but…
Brute forceCryptanalysis
SameBoth recover the message without being given the key
DifferentTries every key, and checks each result for a readable messageUses the recipe and the patterns in the ciphertext, so it does not need to try every key
WhyBrute force needs no knowledge of the recipe, only a way to recognise a real message. Cryptanalysis needs the recipe, and in return it saves the trying

There are two ways (slide 18):

  • Brute force: try every key until the result reads as a real message. Caesar has only 25 useful keys, since key 0 changes nothing. Slide 23 asks you to decrypt IEHKX YKIAXOZE OY YCKKZ with key 4. Key 4 gives EADGT UGEWTKVA KU UYGGV, which is nonsense. Key 6 gives CYBER SECURITY IS SWEET. The slide has a typo, and brute force found the readable message.
  • Cryptanalysis: use knowledge of the recipe and patterns in the ciphertext, instead of trying every key. The double L in HELLO became a double O in KHOOR, so a double letter in the ciphertext points to a double letter in the plaintext.

The ciphers from Caesar to Playfair are done with pen, paper and an alphabet table. Modular arithmetic comes before Hill and RSA, because both need remainders.

Check yourself

An attacker sees that the ciphertext has the same letter twice in a row, and knows the recipe. The attacker guesses that the plaintext has a double letter in the same place. Which method is this?

Yes. The attacker reads a pattern in the ciphertext and uses the recipe. No key is tried, so this is cryptanalysis.
Not this one. Trying each key is brute force. Here no key is tried: the attacker reads the repeated letter and uses the recipe.
