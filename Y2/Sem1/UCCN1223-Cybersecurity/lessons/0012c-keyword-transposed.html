The keyword transposed cipher

Keyword transposed builds a 26-letter strip by filling a grid under the keyword and reading its columns in alphabetical order of the keyword letters. Each message letter is then replaced by the strip letter in the same position.

Bridge: this is the plain keyword cipher (lesson 12a) with one extra step, the grid.

Looks like keyword mixed (lesson 12b), which also builds the same grid from the keyword. Why it differs: the only change is the reading order. Mixed reads the columns in keyword order, left to right (W, I, R, E, L, S). Transposed reads them in alphabetical order (E, I, L, R, S, W). A different reading order gives a different strip, so the same plain letter maps to a different cipher letter.
Looks like real transposition (named in lesson 9), where letters are moved into new positions. The columnar cipher (lesson 13a) is the first one in this topic that does this. Why it differs: transposition keeps every message letter and only moves it. Here every message letter is replaced. The grid only shuffles the alphabet, so this is still a substitution cipher.

Check 1 • Keyword transposed, ASSETS

Encipher CISCO, then decipher IEGP, with the keyword ASSETS.

Reveal step 1: the header

Keyword ASSETS: the two repeated S letters after the first one are dropped, leaving A S E T, 4 columns. Alphabetical order: A, E, S, T.

Reveal step 2: the grid

The other 22 letters, row by row, under A S E T: B C D F / G H I J / K L M N / O P Q R / U V W X / Y Z.

Reveal step 3: the columns and strip

Read in order A, E, S, T: A B G K O U Y, E D I M Q W, S C H L P V Z, T F J N R X. The strip is A B G K O U Y E D I M Q W S C H L P V Z T F J N R X.

Reveal step 4: CISCO enciphered

C→G, I→D, S→V, C→G, O→C. So CISCO → GDVGC.

Reveal step 5: IEGP deciphered

Find each letter on the strip, then read the plain letter at the same position: I is at position 10, so J; E at 8, so H; G at 3, so C; P at 18, so R. So IEGP → JHCR.

In keyword transposed, what happens to each message letter?

Yes. The strip is a shuffled alphabet, so each message letter is replaced, not moved.
Moving letters is real transposition (lesson 9). Here the grid only reorders the strip, and each message letter is replaced.
