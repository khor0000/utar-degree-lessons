Playfair part 4: two full runs

To encrypt a whole message, cut it into pairs, run each pair through the rule that its grid positions pick, and join the outputs in order. The grid stays the same for the whole message.

Bridge: lesson 14b cut a message into pairs, and lesson 14c gave the three rules for one pair. This lesson runs the rules on each pair in turn.

The three rules for each pair are in lesson 14c.

Every run below uses this MONARCHY grid, built in lesson 14a:

MONAR
CHYBD
EFGI/JK
LPQST
UVWXZ

1. A full run: INSTRUMENTS (slide 44)

INSTRUMENTS has eleven letters, so the pad Z completes the last pair (SZ).

IN: rectangle   I → G,  N → A   =  GA
Running: GA
ST: same row   S → T,  T → L   =  TL
Running: GA TL
RU: rectangle   R → M,  U → Z   =  MZ
Running: GA TL MZ
ME: same column   M → C,  E → L   =  CL
Running: GA TL MZ CL
NT: rectangle   N → R,  T → Q   =  RQ
Running: GA TL MZ CL RQ
SZ: rectangle   S → T,  Z → X   =  TX
Final: GATLMZCLRQTX
General rule (a run): cut the message into pairs, apply the rule to each pair in order, and append each output. The final running output is the ciphertext.

2. A second run: ATTACK (slide 45)

ATTACK runs as three pairs (AT TA CK).

AT: rectangle   A → R,  T → S   =  RS
Running: RS
TA: rectangle   T → S,  A → R   =  SR
Running: RS SR
CK: rectangle   C → D,  K → E   =  DE
Final: RSSRDE

3. Check: a fresh message

Run the same steps on a message the deck does not use. OPEN GATE has no double letter, so it makes four pairs with no filler: OP, EN, GA, TE.

Encrypt OPEN GATE with MONARCHY. Type the ciphertext.

Yes. The pairs are OP EN GA TE, giving HV GM IN LK.
Cut the message into pairs first: OP EN GA TE. Then apply a rule to each pair in order, using the grid.
Show the steps
  1. OP: O is at row 1, column 2. P is at row 4, column 2. Same column. O takes the letter below it: H. P takes the letter below it: V. Output HV.
  2. EN: E is at row 3, column 1. N is at row 1, column 3. Rectangle. E takes row 3, column 3: G. N takes row 1, column 1: M. Output GM.
  3. GA: G is at row 3, column 3. A is at row 1, column 4. Rectangle. G takes row 3, column 4: I. A takes row 1, column 3: N. Output IN.
  4. TE: T is at row 4, column 5. E is at row 3, column 1. Rectangle. T takes row 4, column 1: L. E takes row 3, column 5: K. Output LK.

Ciphertext: HV GM IN LK, written as HVGMINLK.
