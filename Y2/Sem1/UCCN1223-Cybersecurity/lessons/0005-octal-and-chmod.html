Octal numbers and chmod

Each rwx set is three on/off bits, so it fits in one digit from 0 to 7, and chmod takes three such digits.

Looks like binary from UCCD1133, where each place is worth a power of 2. Three bits have place values 4, 2 and 1. Octal means base 8, and three bits hold exactly the values 0 to 7, which is why one digit fits one set.

The conversion

r is worth 4, w is worth 2, x is worth 1. Add the ones that are on. Here is the handout’s rwxr-x--- becoming 750.

Using it

chmod changes permissions. Only the owner or root can do it. The first argument is the three digits, and the second is the target:

$ chmod 640 TanAhHock.txt
$ ls -l TanAhHock.txt
-rw-r----- 1 tanah students 0 Nov 3 14:30 TanAhHock.txt

That is Lab 1 Question 3: owner reads and writes (6), group reads (4), others get nothing (0). Always check with ls -l afterwards.

Slide error. Topic 2 slide 35 says 664 is "read/write for owner, read-only for everyone else". By the rule on slide 34, 664 is rw-rw-r--, so the group can write too. "Read-only for everyone else" would be 644.
Critical Exam Trap • Digit Order

The digits follow the string: owner, group, others. 750 and 057 are opposites.

Correct (earns marks)Incorrect (loses marks)
chmod 750 test.txtchmod 057 test.txt

Which digit gives read and write, but no execute?

Yes. 4 + 2 = 6.
Add r = 4 and w = 2.
Procedure drill (fresh input)

Convert rwxr--r-- to digits. Then write the string for 751 and the command giving notes.txt owner read/write and nothing for anyone else.

Reveal the answer

744. Then rwxr-x--x. Then chmod 600 notes.txt.
