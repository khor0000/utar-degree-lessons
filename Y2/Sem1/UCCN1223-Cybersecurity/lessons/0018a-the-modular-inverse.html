The modular inverse part 1: find it and use it

To undo Hill (and later RSA) you need to undo a multiplication mod n. The tool for that is the modular inverse: the whole number x that makes a × x leave remainder 1 mod n. For 3 mod 26, that number is 9.

Why this matters: Hill (lesson 17) scrambles letter numbers by multiplying them by a key. Decryption has to multiply back, and ordinary division does not work on whole-number letter positions. Focus on: finding an inverse with a table, and using it to undo a multiply. Skip for now: the shortcut for large numbers, the formula for a 2×2 matrix inverse, and which numbers have no inverse (lesson 18b). How you'll be tested: by hand, with the table, in Lab 2 (Q3 Hill decrypt, Q4 RSA d). Neither old-format paper asks it. Casio: not confirmed for this method.
Looks like ÷, dividing by 3, since both undo a multiply by 3. It differs because 1/3 is not a whole number, and the cipher needs whole-number letter positions from 0 to 25. So we look for a whole number x with 3 × x ≡ 1 (mod 26).
Looks like the Caesar decryption from lesson 11, which undoes a shift by shifting back. It differs because Hill multiplies. Undoing a multiply is a multiply by a different number, not a shift in the other direction.

1. The paradox: there is no division mod 26

Normally you undo ×3 by ÷3. But mod 26 the only numbers are 0 to 25, and 1/3 is not one of them. We multiply by a whole number that does the job 1/3 would do. That number is the inverse.

The inverse is not 1/3, and it is not a fraction. It is the whole number x for which 3 × x leaves remainder 1 mod 26.

Modular inverse (new term). What it is: a whole number x that undoes multiplying by a, mod n. What value it holds: one number from 0 to n−1, written a−1. Why needed: decryption multiplies back, and there is no division mod n. So the inverse of 3 mod 26 is 9, written 3−1 = 9 (mod 26).

3. Undo the multiply

Now use the 9. The plain letter U is 20 (A=0). Encrypt it with ×3, then decrypt with ×9. Each stage adds one step:

Check 1: fresh input, find x in 7x ≡ 1 (mod 26)

Use the table method. Try before you open the reveal.

Reveal, step by step
  1. Remainders of 7 × x mod 26, for x = 1 to 15: 7, 14, 21, 2, 9, 16, 23, 4, 11, 18, 25, 6, 13, 20, 1.
  2. The first remainder of 1 is at x = 15: 7 × 15 = 105, and 105 − 104 = 1.
  3. Answer: x = 15. So 7 has inverse 15 mod 26.
