Playfair: the three encryption rules

Yes: each pair is encrypted by one of three rules, chosen by where its two letters sit in the grid. Same row: each letter takes the letter to its right. Same column: each letter takes the letter below it. Neither: each letter takes the corner in its own row, which lies in the other letter's column.

Bridge: lesson 11 moved each letter a fixed number of places, with wrap. The first two rules do the same, one place along a row or a column, with wrap. The grid is what changes the answer for each pair.
Looks like the Caesar shift (lesson 11), but... both move a letter a fixed step and wrap at the end. Caesar always moves by the key. Playfair moves one cell, and only if the pair shares a row or a column. Why it differs: the step is a position in the grid, not a number in the key, so wrap happens after 5 cells, not 26.

3. Neither: NT gives RQ (slide 42)

If the letters share neither a row nor a column, they are two opposite corners of a rectangle. Each letter is replaced by the corner in its own row.

4. Fresh checks

These inputs are not on the slides. Each one uses a rule the walks above showed. Work from the MONARCHY grid in lesson 14a.

Encrypt AR with MONARCHY.

Yes. A takes R, and R wraps to M.
A and R are in row 1, so this is the same-row rule. Each takes the letter to its right. R is in the last column, so it wraps to column 1: M.
Show the steps
  1. A is at row 1, column 4. R is at row 1, column 5. Same row.
  2. A takes the letter to its right: R.
  3. R is in the last column, so it wraps to column 1 of row 1: M.
  4. Answer RM.

Encrypt CU with MONARCHY.

Yes. C takes E, and U wraps to M.
C and U are in column 1, so this is the same-column rule. Each takes the letter below. U is in the bottom row, so it wraps to the top of column 1: M.
Show the steps
  1. C is at row 2, column 1. U is at row 5, column 1. Same column.
  2. C takes the letter below it: E (row 3).
  3. U is in the bottom row, so it wraps to the top of column 1: M (row 1).
  4. Answer EM.

Encrypt BE with MONARCHY.

Yes. B takes C, and E takes I.
B is in row 2 and E in row 3, in different columns. So it is a rectangle. B takes the letter in row 2 at E's column: C.
Show the steps
  1. B is at row 2, column 4. E is at row 3, column 1. Rectangle.
  2. B takes row 2, column 1: C.
  3. E takes row 3, column 4: I.
  4. Answer CI.

5. Pick the rule

E and L sit in the same column. Which rule applies to the pair E L?

Yes. Both letters share column 1, so each takes the letter below it.
E and L share a column, not a row, and they are different letters. Each takes the letter below it.
