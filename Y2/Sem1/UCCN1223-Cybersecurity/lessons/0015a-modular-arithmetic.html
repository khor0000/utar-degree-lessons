Modular arithmetic part 1: the remainder that wraps

mod n gives the remainder after dividing by n, and the answer is always from 0 to n−1. Read a ≡ b (mod n) as "a and b leave the same remainder when divided by n".

Why this matters: the Caesar strip in lesson 11 wraps past Z back to A. Modular arithmetic is the calculation behind that wrap, written with numbers, so a shift that runs past 25 still lands on a letter. Focus on: what mod 26 returns, and how to read ≡. Skip for now: negative numbers, which are lesson 15b, and finding a modular inverse, which is not needed for the papers and is skipped for now. How you'll be tested: by hand. Old-format Oct 25 Q1 used mod 26 as one step of a Hill encryption (4 marks, positive numbers only). The Casio fx-570EX: no mod key is confirmed (the notes say unverified), so do it by hand as shown below.
Bridge: lesson 11 wrapped letters by reading a strip. This lesson does the same wrap with a division-style calculation, so it works for any number, not just letters.
Looks like division, which you already know, but the answer is the leftover, not the whole part. Dividing 30 by 26 gives 1 whole time, with 4 left over. The leftover is the answer: 30 mod 26 = 4. The whole part, 1, is the quotient, and mod ignores it.
Looks like = from school, but ≡ does not mean the two sides are the same number. 3 ≡ 29 (mod 26) is true, and 3 is not 29. It means both leave the same remainder when divided by 26.

The rule, in one box. To work out x mod n: (1) count how many n fit in x; (2) take them away; (3) what is left is the answer. The number you divide by, n, is the modulus: a whole number that sets where the wrap happens. In a Caesar cipher it is 26, the number of letters. Deck example: 33 mod 26 = 7 (Topic 3a slide 49). 26 fits once, and 33 − 26 = 7.
You might reasonably wonder: why does A count as 0, not 1? Because the wrap has to land on 0 to 25, one number for each letter. The deck uses this (Topic 3a slide 48: "A=0 ... Z=25"), and Lab 2 assumes it too. If A were 1, Z would be 26. Any mod 26 result is 0 to 25, and 0 would then have no letter, because the letters would be numbered 1 to 26. With A = 0, the 26 possible results 0 to 25 match the 26 letters exactly.
Critical Exam Trap • The Remainder Is Never n

A remainder is always smaller than the modulus, so the answer runs from 0 to n−1. Writing n as the answer loses the mark.

2. ≡ says two numbers match after the wrap

Read a ≡ b (mod n) as "a is congruent to b, modulo n": a true or false statement that two numbers leave the same remainder. Here 3 ≡ 29 (mod 26) is true, because 3 mod 26 = 3 and 29 mod 26 = 3.

Check yourself

Check 1: fresh input, Caesar key 9

Encrypt the letter W with key 9. Work out the position of W, add 9, and wrap with mod 26. Try it on paper before you open the reveal.

Reveal, step by step
  1. A is 0, so W is position 22.
  2. Add the key: 22 + 9 = 31.
  3. How many 26s fit in 31? One. Take it away: 31 − 26 = 5.
  4. Position 5 is F. So W → F.

What is 26 mod 26?

Yes. 26 fits once, and nothing is left: 26 − 26 = 0.
Not this one. 26 fits exactly once, so the leftover is 0. The answer always runs from 0 to 25.

The statement 3 ≡ 29 (mod 26) means:

Yes. Both 3 and 29 wrap to 3 when you take mod 26, so they leave the same remainder.
The sign ≡ means "same remainder", and 26 is the modulus. Read it as "3 and 29 leave the same remainder".
