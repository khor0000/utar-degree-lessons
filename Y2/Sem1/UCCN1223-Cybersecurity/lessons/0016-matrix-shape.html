Matrix shape: when can two matrices multiply?

Two matrices (grids of numbers) can be multiplied only when the columns of the first match the rows of the second. If they match, the result has the rows of the first and the columns of the second.

Why this matters: a grid of numbers can be multiplied by a column of numbers, but only when the sizes fit. A wrong size gives no answer at all, so the size rule comes before any arithmetic. Focus on: the size rule, and reading the size of the result. Skip for now: multiplying grids bigger than the 2×2 and 2×1 shapes used here. How you'll be tested: by hand, as one step of a later encryption question (old-format paper Oct 25 Q1, 4 marks; the format changed from June 2026, so the exact question is not confirmed). 1. When is a product allowed?

A matrix is a rectangle of numbers, written rows × columns. Each number in it is an entry.

Matrix. What it is: a rectangle of numbers. What it holds: one number per entry. Why needed: a key is a matrix, and it does the mixing in a later cipher.
Looks like the row-times-column multiply from school, but the size rule decides whether it is allowed at all.

For A × B, the columns of A must equal the rows of B. If they match, the product exists, and its size is rows of A × columns of B.

A block is a group of letters encrypted together. Here it is a column vector, one column of numbers, so a 2×2 grid times a 2×1 block is always allowed. Two letters in, two letters out.

Which pair can be multiplied, A × B?

Yes. A has 2 columns and B has 2 rows, so they match. The product is 3×4.
Compare the columns of A with the rows of B. Only one pair has the same number on both sides of the multiply.
