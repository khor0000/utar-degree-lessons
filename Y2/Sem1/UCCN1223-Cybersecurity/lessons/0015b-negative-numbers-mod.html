Modular arithmetic part 2: negative numbers

A negative number still gets a remainder from 0 to n−1: keep adding n until the answer lands in that range.

Bridge: lesson 15a counted how many 26s fit in a positive number and kept the leftover. For a negative number there is no leftover to keep, so this lesson adds 26 instead until the answer is in range.
Looks like % in C++ (UCCD1024), but it differs for negative numbers. For positive numbers both give the same answer: 29 % 26 = 3. For a negative number C++ keeps the sign, so -7 % 26 = -7, while mod in cryptography gives 19. Why it differs: a cipher needs every answer to be a letter position from 0 to 25.

The rule, in one box. Negative x: keep adding n until it lands in 0 to n−1.

Check 2: fresh input, decrypt D with Caesar key 9

Decrypting shifts the letter back by the key. Decrypt the letter D with key 9. Work out the position of D, subtract 9, and wrap with mod 26. Try it on paper before you open the reveal.

Reveal, step by step
  1. A is 0, so D is position 3.
  2. Subtract the key: 3 − 9 = −6. This is negative, so it is not a position yet.
  3. Add the modulus 26: −6 + 26 = 20. 20 is between 0 and 25, so stop.
  4. Position 20 is U. So D → U.
