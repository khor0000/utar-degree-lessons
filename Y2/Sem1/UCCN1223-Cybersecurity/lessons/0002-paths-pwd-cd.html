Paths: pwd, cd and ..

A path is the written route to a folder, and the shell always remembers which folder you are in.

Looks like the folder tree on Windows, with C:\Users\.... Linux uses / instead of \, and it has one tree with no drive letters, because every disk is attached somewhere under the top folder.

Two ways to write a route

A directory is a folder. The top one is the root directory, written /. Your working directory is the folder the shell is in now.

An absolute path starts with /, so it starts from the top and works from anywhere. A relative path has no leading /, so it starts from where you are. The / at the start means "the top", and any other / separates folder names. In a path, .. means the parent folder, one step up.

Press the buttons or the ← → keys and watch the highlighted folder.

$ pwd
/home/student
$ mkdir ahhock

$ cd ahhock

$ cd ..

$ cd /home/student/ahhock

$ cd /home/student
Critical Exam Trap • The Leading Slash

A leading / restarts from the top. From /home/student, /ahhock looks for a folder directly under root, and it fails.

Correct (earns marks)Incorrect (loses marks)
cd ahhockcd /ahhock

You are in /home/student/ahhock. Where does cd .. take you?

Yes. .. is one step up, to the parent.
.. moves exactly one level.
Paper task (fresh input)

You are in /var/log. Write two different commands that go to /var, then one that goes to /var/log/apt.

Reveal the answer

cd .. and cd /var, then cd /var/log/apt. From /var/log, cd apt also works.
