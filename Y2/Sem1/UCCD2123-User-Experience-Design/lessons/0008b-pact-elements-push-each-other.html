Lesson 8b · Tutorial 1 Q7–Q8

PACT elements push each other

PACT elements push each other. No fixed rule says which element changes which. Any element can push any other, and a PACT analysis is a snapshot that you revisit.

The book names only one fixed link. It says that "activities (and the contexts within which they take place) establish requirements for technologies that in turn offer opportunities that change the nature of activities."

Two words first. Requirements are what a system must do and the qualities it should have. Opportunities are new possibilities a technology offers.

Lesson 8's no-signal example showed a change without naming it. Here each example says which element pushed which, and in what direction.

Four pushes, one per stage

A push is one element changing another. The arrow runs from the element that changes to the one that is changed. Step through the four examples:

Technology pushes activity. QR e-wallets change how people pay at a pasar malam, with no change to count.

Context pushes activity. The MCO moved grocery shopping online.

People push technology. Elderly users with poor eyesight need larger text and a voice option.

Context pushes technology. In a noisy kopitiam a beep is lost, so the phone vibrates instead.

The four arrows point in different directions. There is no chain you must follow.

More than one at once

Several pushes can happen together. The MCO changed Contexts and Activities, and it also changed People, because older users came online for the first time.

Change is not a mistake

A PACT analysis is a snapshot, a picture of one moment. People, contexts and technologies drift. Before QR e-wallets, most kopitiams took only cash. An earlier analysis is not wrong just because the world has moved on: it was right for its time. Designers revisit it when something changes, or at each iteration, one round of designing and checking. Working rule (not in the book): the book sets no schedule for revisiting.

Check yourself

Grab drivers start using in-app navigation, so they stop carrying paper maps. Which push is this?

Right. The app (technology) changed how drivers find their way (activity).
Look at what changed first. The app came in, and then the activity of finding routes changed. The arrow runs from technology to activity.

A kopitiam phone app switches from a beep to vibration, because the stall is too loud to hear one. Which push is this?

Right. The noise (context) changed the alert the phone uses (technology).
Check which changed first. The noise came first, and the alert changed in response, so the arrow runs from context to technology.
Produce it • fresh input

Give one new example each of two different pushes, set on the Kampar campus (for example the library, a hostel or a canteen). Name the direction of each.

reveal model answer

Technology pushes activity. A QR code on the hostel laundry machine means students stop queuing with coins. Context pushes technology. A dim corridor outside the hostel door pushes the keypad to add a backlit display.
