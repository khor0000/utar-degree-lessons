Borderline sentences: apply the test to each one

A borderline sentence can be conceptual on one point and concrete on another. Apply the two questions to each sentence separately, and a sentence is concrete if either question says yes.

Lesson 17b gave the two questions. This lesson applies them to sentences that look conceptual but are not.

Looks like checking a menu line by line for allergens. One dish can be safe on one ingredient and not on another.

A sentence that looks conceptual

Take this sentence: "Students get a message on their phone when the order is ready." It looks conceptual, because it is short and plain. Apply the two questions. "A message when ready" describes the outcome, which the conceptual rung already allows, so the notification itself is conceptual. "On their phone" names a device, which the first question catches. The sentence is therefore concrete on the device and conceptual on the outcome.

You might reasonably wonder whether any named control makes a scenario concrete. Under this test, yes. "Students are told when the order is ready" is conceptual, while "Students tap the Ready button" is concrete.

Where the slides and the book differ

Lecture 8 (PDF p3) lists "consider filtering options" under conceptual design, with the example of price range and category. The book's wording would treat a named filter control as concrete. So this course follows the book. The slide's idea fits a function, "narrow the results", which is conceptual. Name the control only when the scenario has one.

Produce it • closed book • Tutorial 2 Q8

Close lessons 17 to 17c. Answer Q8 on paper: is the difference between conceptual and concrete scenarios only a matter of length? Say no, state the difference, then take one sentence of your own canteen scenario and apply the two questions to it.

reveal model answer

No. The difference is level of abstraction. A conceptual scenario describes what people do and get, without naming a device, control or split of functions. A concrete scenario adds those decisions, so it fixes the interface and who does which part. The line is not clean: a scenario can be concrete about some aspects and conceptual about others. For example, "Students order a canteen meal from their phone" names a device, so it is concrete on that point, while "Students order a canteen meal in advance" is conceptual. Apply the two questions to each sentence: does it name a device, screen or control, and does it say who does which part?
