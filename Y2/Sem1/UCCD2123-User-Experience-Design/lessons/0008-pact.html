PACT: four things in one sentence

PACT stands for People, Activities, Contexts and Technologies, the four elements to consider when designing an interactive system. All four fit in one sentence: People use Technologies to do Activities in Contexts.

In Lesson 1 the signal, the queue and the stall owner all shaped the experience. PACT is a checklist that stops you forgetting pieces like those. Nothing you've seen in this course works like it yet.

Build one sentence

People: who is using it? Here, a student in a rush.

Activities: what are they trying to do? Collect a parcel.

Contexts: where and under what conditions? A crowded shop at 6 pm.

Technologies: what do they use? A phone app showing a QR code. The sentence is complete.

Now change one box: there is no signal. The same person and task need a different design. This is why PACT matters: the four elements depend on each other.

Each element, with one example

ElementQuestionLibrary kiosk example
PeopleWho, and how do they differ?Students, staff, first-time users
ActivitiesWhat do they do?Borrow and return books
ContextsIn what conditions?Quiet library, busy before exams
TechnologiesWhat input, output, communication, content?Student ID scan, screen, link to library database

Listing the variety of each element for a real problem is a PACT analysis, which scopes the design problem (Lecture 1, p31). The full sub-parts are on the PACT sheet.

reveal model answers

Analysis (sample). People: students, the laundry operator. Activities: pay, start a wash, check if it is finished. Contexts: crowded on weekends, wet and dim laundry room. Technologies: phone camera for QR input, screen output, wi-fi or mobile data, machine status content.

Q7. PACT stands for People, Activities, Contexts and Technologies. It is important because it is a human-centred way to understand and scope a design problem. The elements are interdependent, so changing one changes what a good design is. For example, a parcel QR needs offline support if the shop has no signal.
